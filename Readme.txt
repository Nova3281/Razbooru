RAZBOORU
Razbooru is a heavily customized and modernized fork of the original Zenbooru
image board viewer. It features extensive updates, including modern API handlers
for updated Booru architectures (e621, Danbooru v2, Moebooru, Gelbooru), local
score and favorite filtering, and security bypasses via the anyOS extension.
